| O quê | Onde |
|---|---|

| **Slides da apresentação** (PDF) | https://giuliano-economics.github.io/painel-sfc/apresentacao-seminario.pdf |

Os parâmetros dos modelos são ilustrativos, não ajustados a dados reais.
